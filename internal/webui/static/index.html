How this works

Upgrades come first, newer versions of your group leading, then entries not downloaded, then ones whose release group needs a look, then entries SeaDex names no best for. Optional upgrades are ones where you already have a SeaDex alt. Each size shows the download, and below it how much your library grows (+) or shrinks (−). A change marked ≈ is the download against everything on disk for that season or film, used when its files could not be matched to yours one by one.

Seasons and films below the minimum score

How this works

Files that score below the minimum are not on a SeaDex best grab, as far as Sonarr and Radarr know. Where the scout says you already hold the SeaDex best, or a file was imported from a torrent SeaDex marks as best, Fix flags gives those files the Freeleech25 + Scene flags a best grab carries; other files are left alone. Not matched titles have no SeaDex entry the scout could map to them, so searching will not help. Where SeaDex lists a better release, Search asks Sonarr or Radarr to look now.

Sonarr and Radarr queues

How this works

Import takes the files Sonarr matched to episodes with no file or a file below the minimum score, as hardlinks, with the grab's indexer flags. It overrides only Sonarr's "episode was unexpected" check, which stops packs that hold more than their name says. Remove drops the entry from the queue only: the torrent keeps seeding and nothing is blocklisted. A pack whose matched files are all imported already shows Already imported: its extra files keep it queued, so remove it (auto mode does this every 30 minutes).

Torrents not in the library

How this works

None of these torrents' files is hardlinked into a Sonarr or Radarr root folder any more, so they only take space. Delete removes the torrent and its data in qBittorrent, after checking again. Torrents from a private tracker (AnimeBytes included), torrents that share files with another torrent, and torrents with missing files are listed but never offered for deletion.
